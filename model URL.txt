================================================================================
ССЫЛКИ НА ВСЕ МОДЕЛИ-КАНДИДАТЫ ДЛЯ АНАЛИЗА И ЭКСПЕРИМЕНТОВ (КТ 2 И КТ 3)
Проект: ТЗ 4. Локальный редактор изображений (PepeShop)
Целевое железо: NVIDIA GeForce GTX 1660 Ti (6 ГБ VRAM), 16 ГБ RAM
================================================================================

1. НАПРАВЛЕНИЕ: ГЕНЕРАЦИЯ ИЗ ТЕКСТА (Txt2Img)
--------------------------------------------------------------------------------
1.1. SDXL Turbo INT8 [Чемпион проекта / Финальный прототип]:
     - Hugging Face (INT8 квантование): https://huggingface.co/imgailab/sdxl-turbo-torch-int8
     - Hugging Face (Оригинал Stability AI): https://huggingface.co/stabilityai/sdxl-turbo
     - Описание: 1 шаг, время 1.94 с, VRAM 4.71 ГБ, фотореализм 512x512.

1.2. SDXL Base 1.0 (FP16):
     - Hugging Face: https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0
     - Описание: Классическая модель 1024x1024, время 8.5 с, VRAM 5.82 ГБ (на грани OOM для 6 ГБ).

1.3. FLUX.1-schnell (GGUF Q2_K / Q4_K):
     - Hugging Face: https://huggingface.co/city96/FLUX.1-schnell-gguf
     - Описание: SOTA 12B DiT-трансформер 2024 года, 4 шага, время 38 с, требует CPU-offload.


2. НАПРАВЛЕНИЕ: УДАЛЕНИЕ ФОНА (Background Removal)
--------------------------------------------------------------------------------
2.1. BRIA RMBG-2.0 [Чемпион проекта / SOTA 2024]:
     - Hugging Face: https://huggingface.co/briaai/RMBG-2.0
     - Архитектура: BiRefNet (Bilateral Reference Network).
     - Описание: Волосы, шерсть, стекло, полупрозрачные детали. Время 0.28 с, VRAM 1.2 ГБ, mIoU = 0.948.

2.2. BRIA RMBG-1.4 (ONNX / CPU):
     - Hugging Face: https://huggingface.co/briaai/RMBG-1.4
     - Описание: Компактная модель (170 МБ), время 0.95 с на CPU, mIoU = 0.912 (выполняет условие ТЗ без GPU).

2.3. BiRefNet (Базовая архитектура):
     - Hugging Face: https://huggingface.co/ZhengPeng7/BiRefNet
     - GitHub: https://github.com/ZhengPeng7/BiRefNet

2.4. U2-Net / rembg (Классический CPU-фолбэк):
     - GitHub репозиторий: https://github.com/danielgatis/rembg
     - Веса модели (u2net.onnx): https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2net.onnx
     - Описание: 170 МБ, надежная работа без видеокарты, mIoU = 0.901.


3. НАПРАВЛЕНИЕ: ЧИСТОЕ СТИРАНИЕ ОБЪЕКТОВ (Object Removal / Content-Aware)
--------------------------------------------------------------------------------
3.1. LaMa (Large Mask Inpainting) [Чемпион проекта / Финальный прототип]:
     - GitHub авторов: https://github.com/advimman/lama
     - GitHub IOPaint (Sanster): https://github.com/Sanster/IOPaint
     - Прямая ссылка на ONNX веса: https://github.com/Sanster/models/releases/download/add_lama/lama.onnx
     - Описание: Fast Fourier Convolutions (FFC). Мгновенное стирание (0.06 с), VRAM 0.48 ГБ, PSNR 34.2 dB.


4. НАПРАВЛЕНИЕ: ГЕНЕРАТИВНЫЙ ИНПЕЙНТИНГ ПО МАСКЕ (Inpainting with Text)
--------------------------------------------------------------------------------
4.1. FLUX.1-Fill-dev (GGUF Q2_K) [SOTA Творческий выбор]:
     - Hugging Face: https://huggingface.co/city96/FLUX.1-Fill-dev-gguf
     - Прямой файл весов Q2_K: https://huggingface.co/city96/FLUX.1-Fill-dev-gguf/blob/main/flux1-fill-dev-Q2_K.gguf
     - Описание: 12B Flow-Matching DiT, идеальная интеграция света/тени, время 36 с (норматив ТЗ <= 60 с).

4.2. SDXL Inpainting 0.1 (FP16):
     - Hugging Face: https://huggingface.co/diffusers/stable-diffusion-xl-1.0-inpainting-0.1
     - Описание: Разрешение до 1024x1024, время 6.8 с, VRAM 4.85 ГБ.

4.3. RealVisXL V4.0 Inpainting:
     - Hugging Face: https://huggingface.co/SG161222/RealVisXL_V4.0_Inpainting
     - Описание: Фотореалистичный инпейнтинг лиц и текстур.


5. НАПРАВЛЕНИЕ: РЕДАКТИРОВАНИЕ ПО ТЕКСТУ БЕЗ МАСКИ (Text-Guided Edit)
--------------------------------------------------------------------------------
5.1. FLUX.1 Kontext (GGUF Q2_K):
     - Hugging Face: https://huggingface.co/city96/FLUX.1-dev-gguf
     - Описание: Инструктивное редактирование («сделай ночь», «добавь снег»), высокое качество деталей.

5.2. CosXL Edit (Stability AI):
     - Hugging Face: https://huggingface.co/stabilityai/cosxl
     - Веса модели: cosxl_edit.safetensors
     - Описание: SDXL с EDM2 и косинусным расписанием для изменения стиля и объектов, время 7.5 с.
