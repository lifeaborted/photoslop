## 4. Метрики

| Метрика | Как считаем | Целевое значение из ТЗ |
| :--- | :--- | :--- |
| **mIoU (Mean Intersection over Union)** | $\text{mIoU} = \frac{|A \cap B|}{|A \cup B|}$ через `scipy` и `numpy` по альфа-маскам | $\ge 0.90$ (строго по ТЗ) |
| **Boundary IoU** | IoU по граничным пикселям маски шириной 3–5 px (оценка точности волос и мелких деталей) | $\ge 0.82$ |
| **PSNR / SSIM** | Метрики восстановления неповрежденных областей при инпейнтинге через `scikit-image` | $\text{PSNR} \ge 30\text{ dB}$, $\text{SSIM} \ge 0.92$ |
| **CLIP Score** | Косинусная близость текстового эмбеддинга промпта и визуального эмбеддинга `ViT-B/32` | $\ge 0.28$ |
| **Время генерации (Latency)** | Высокоточное время инференса модели $512\times512$ через `time.perf_counter()` | $\le 60\text{ с}$ (норматив ТЗ) |
| **Пиковое потребление VRAM** | `torch.cuda.max_memory_allocated()` во время инференса | $\le 5.8\text{ ГБ}$ (лимит 6 ГБ VRAM) |

## 5. План экспериментов

1. **Этап 1: Сегментация фона (CPU vs GPU)**  
   - Запуск BRIA RMBG-2.0, BRIA RMBG-1.4 и U2-Net на тестовом наборе из 100 изображений.
   - Фиксация mIoU, времени выполнения на GTX 1660 Ti и отдельно на CPU (Intel/AMD).
   - Проверка выполнения условия ТЗ ($\text{mIoU} \ge 0.9$ без видеокарты).

2. **Этап 2: Генерация Txt2Img в условиях лимита 6 ГБ VRAM**  
   - Замер времени инференса и пикового VRAM для SDXL Turbo INT8 (1 шаг), SDXL Base FP16 (4 шага) и FLUX.1 Schnell Q2.
   - Оценка артефактов VAE при FP16-декодировании на GPU архитектуры Turing.

3. **Этап 3: Сравнительный анализ инпейнтинга**  
   - Тестирование LaMa на задаче удаления нежелательных объектов (скорость, артефакты размытия).
   - Сравнение генеративного инпейнтинга SDXL Inpainting vs FLUX.1 Fill Dev Q2 по критериям соответствия промпту и удержания лимита 60 секунд.

4. **Этап 4: Агрегация телеметрии**  
   - Автоматический сбор логов из [`logs/log.txt`](file:///c:/others/Codes/pepeshop/logs/log.txt) средствами Loguru и генерация итоговой таблицы для КТ 3.
